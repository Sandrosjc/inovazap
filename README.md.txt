# 🚀 Inova Zap

SaaS Multi-segmento para Atendimento, Vendas e Gestão Automatizada via WhatsApp.

![Status](https://img.shields.io/badge/status-em%20desenvolvimento-yellow)
![License](https://img.shields.io/badge/license-Proprietária-red)

## 🎯 Visão

O **Inova Zap** unifica atendimento, agendamento, vendas e gestão em um único ecossistema, com o WhatsApp como canal central de comunicação.

Atende **dois grandes perfis**:
- 👨‍⚕️ **Profissionais Liberais** — médicos, dentistas, psicólogos, advogados, etc.
- 🛒 **Comércios** — supermercados, farmácias, restaurantes, etc.

## 🧩 Motor Dinâmico de Profissões (Core Intelligence)

> Ao digitar **qualquer profissão**, o Inova Zap desbloqueia **instantaneamente** uma sequência específica de paradigmas de auto-atendimento e workflows de WhatsApp — este é o núcleo inteligente da plataforma.

## 🛠️ Stack Atual

- **Backend:** Node.js + Express
- **Frontend:** HTML5 + CSS3 + JavaScript (Vanilla)
- **Motor Dinâmico:** Config-driven (JSON paradigms)
